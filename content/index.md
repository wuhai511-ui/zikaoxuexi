## 🗂 科目内通用结构

```
00178-市场调查与预测/
├── 00-考试导航.md          # 考纲/教材/真题档案/高频分布（科目 hub）
├── 01-章节考点/            # 每章一个笔记：知识树 + 考点卡 + 易错辨析
├── 02-历年真题/            # 每套卷一个文件，题目带章节/题型/考点标注
├── 03-重难点专题/          # 简答 TOP / 论述 TOP / 计算专项（真题反推）
├── 04-背诵手册/            # 名词解释/简答论述/公式速查 + 可打印合订版
├── 05-刷题自测/            # Obsidian 折叠式自测 + 错题收集
└── 06-学习计划/            # 周冲刺日历 + 每日打卡清单
```

## 🚀 使用方式（00178 首轮冲刺）

1. 从 [[00178-市场调查与预测/00-考试导航]] 出发，了解题型分值与高频考点；
2. 按周推进 [[00178-市场调查与预测/06-学习计划/冲刺日历-W1-W6]]；
3. **背诵为主**：打印 [[00178-市场调查与预测/04-背诵手册/背诵手册-合订版]]；
4. **自测为辅**：在 Obsidian 内完成 [[00178-市场调查与预测/05-刷题自测/客观题自测-分章节]] 等，错题记入 [[00178-市场调查与预测/05-刷题自测/错题收集]]。
