# 计算公式速查（计算题 18 分专用）

> 用法：先默写公式 → 对照 → 用真题/自测演练。凡公式后的【真题】为该题型实际考过的考期，见 [[02-历年真题/真题索引]]。
> 真题规律：37 题=抽样/统计类，38 题=预测计算类。**写步骤才能拿分：公式 → 代入（带单位）→ 结果 → 一句结论。**

---

## 一、描述统计（单选/计算 37 题备手）

### 1. 集中趋势
- 算术平均数：`x̄ = Σx / n`
- 中位数：排序后位置 (n+1)/2 的值（n 为奇数取中间；n 为偶数取中间两数平均）
- 众数：出现次数最多的值（**不要求唯一**）

### 2. 离散程度
- 极差 = 最大值 − 最小值
- 样本方差：`s² = Σ(x − x̄)² / (n − 1)`
- 样本标准差：`s = √s²`（方差开根号，与原数据同单位）
- **变异系数**：`CV = s / x̄ × 100%`（标准差 ÷ 均值，消除量纲影响）【真题：2022-04 单选17、2025-04 单选17/计算37 前后用】
- **四分位点内距**：`IQR = Q₃ − Q₁`，其中 Q₁ 与 Q₃ 用排序位置法求（位置 (n+1)/4 与 3(n+1)/4，取邻近值线性插值或就近取值，按教材口径）【真题：2025-04 计算37；2026-04 名解28】

### 3. 频率
- `频率 = 某组次数 / 总次数`（相对次数，∈[0,1]）【2021-04 名解28】

## 二、抽样与推断（37 题主力）

### 4. 标准误（抽样平均误差）
- 总体 σ 已知：`SE = σ / √n`；总体 σ 未知：`SE = s / √n`
- 样本均值落在 x̄ ± k·SE 内的概率（中心极限定理）：k=1 → **68.27%**，k=2 → **95.45%**，k=3 → **99.73%** 【真题：2021-04 单选10、2024-10 单选10】

### 5. 总体均值置信区间（重点 ★★★）
```
x̄ ± Z·(s/√n)
```
- 置信度 95%  → Z = 1.96
- 置信度 95.45% → Z = 2（高频，出题最喜欢 95.45%）
- **总体总量推算**：`总量区间 = N × (x̄ − Δ, x̄ + Δ)`（N 为总体单位数，Δ = Z·s/√n）【真题：2021-04 计算37（49人、x̄=24.80、s=5、95% → ≈23.40~26.20 元）；2023-04 计算37（同题重考）；2024-04 计算37（5000 人、x̄=3000、SE=50、Z=2 → 区间 ±100 元 → 总额约 1450 万~1550 万元）；2026-04 计算37（n=50、x̄=32、s=6、Z=1.96 → SE≈0.85，区间 [30.34, 33.66]）】

### 6. 样本容量确定（计算 38 或 37 题候选 ★★）
- 均值型（重复抽样）：`n = Z²σ² / Δ²`（Δ = 允许误差）
- 比例型：`n = Z²·p(1−p) / Δ²`（p 为成数/比例，无资料时取 p=0.5 得最大样本）
- 有限总体校正：`n′ = n·N / (N + n)`（N 有限且 n/N 较大时用）
【真题：2022-10 计算37（σ=4、Δ=1、Z=2 → n=4×16/1=64 户，有限总体 N=60000 校正后仍≈64）；2025-04 计算38（p 存疑：p=0.05% → n≈20；p=5% → n≈1900，见真题文件【待核实】）】

### 7. 分层抽样样本分配（计算 37 候选 ★★）
- 比例分配：`nᵢ = n × Nᵢ/N`（按各层规模比例）
- **Neyman 最佳分配**：`nᵢ = n × (Nᵢ·σᵢ) / Σ(Nⱼ·σⱼ)`（考虑各层标准差，σ 大者多抽）
【真题：2023-10 计算37（50 万消费者分层最佳抽样）；2024-10 计算37（20000 户分层最佳抽样）——两步：先算 ΣNᵢσᵢ 作分母，再逐层算 nᵢ】

## 三、时间序列预测（38 题主力）

### 8. 简易平均法
- 算术平均：`ŷ = (y₁+…+yₙ)/n`（以观察期均值为预测值）【2025-04 单选18】
- 加权平均：`ŷ = Σ(wᵢ·yᵢ) / Σwᵢ`，**原则：越接近预测期的数据权重越大** 【2023-10 单选17】
- 几何平均：n 期环比发展速度连乘开 n 次方

### 9. 简单移动平均
- `M̂ₜ₊₁ = (yₜ₋ₖ₊₁ + … + yₜ) / k`（k = 跨越期数）

### 10. 加权移动平均（★★★ 出镜率最高：2021-04、2023-10、2024-04、2026-04）
```
M̂ₜ₊₁ = (w₁·yₜ₋ₖ₊₁ + w₂·yₜ₋ₖ₊₂ + … + wₖ·yₜ) / Σwᵢ
```
- 真题常用 k=3、权数 1,2,3（**距预测期最近的数据权重 3**）：
  `M̂ₜ₊₁ = (1·yₜ₋₂ + 2·yₜ₋₁ + 3·yₜ) / 6`
- 例：6 期销量 10,12,11,10,13,12（百件），预测第 7 期：
  `M̂₇ = (1×10 + 2×13 + 3×12)/6 = (10+26+36)/6 = 12.0`（百件）
【2021-04 计算38 = 2024-04 计算38 同题重考】

### 11. 一次指数平滑
```
ŷₜ₊₁ = α·yₜ + (1−α)·ŷₜ
```
- 本期预测 = α×本期实际 + (1−α)×上期预测（α 为平滑系数 0<α<1）【2024-04 单选18】

### 12. 二次移动平均（线性趋势外推 ★）
- 记一次移动平均序列 Mₜ⁽¹⁾，二次移动平均 Mₜ⁽²⁾ = 对 Mₜ⁽¹⁾ 再做 k 期移动平均
- `aₜ = 2Mₜ⁽¹⁾ − Mₜ⁽²⁾`；`bₜ = 2/(k−1)·(Mₜ⁽¹⁾ − Mₜ⁽²⁾)`
- 预测：`ŷₜ₊ₗ = aₜ + bₜ·L`
【2023-04 计算38：10 年销量、N=4 二次移动平均预测未来两年——真题数据不全，重点掌握公式与步骤】

### 13. 季节指数法（季节变动预测 ★）
- 思路：`季节指数 = 同季平均水平 / 全期总平均水平`
- 预测：某季预测值 =（预测期年总量/年平均值水平）× 该季季节指数（或按"年预测均值 × 季节指数"），口径以教材为准
【2022-10 计算38：四年分季资料、已知第五年一季度 16 万吨，用季节指数推其余各季——方法题，会列步骤】

## 四、因果/其他预测（38 题候选）

### 14. 一元线性回归（因果关系分析预测法）
- 回归方程：`ŷ = a + bx`
- `b = Σ(x−x̄)(y−ȳ) / Σ(x−x̄)²`（斜率）
- `a = ȳ − b·x̄`（截距）
- 步骤：画散点看线性 → 求 a、b → 代 x 预测 y → 说明适用与局限 【2022-04 简答35、2026-04 简答34"回归分析基本步骤"】

### 15. 基数迭加法（比例推算，属因果关系分析预测法）
- 思路：以基期实际值为基数，将影响预测目标各因素的增减幅度（比率或绝对额）逐项迭加，得预测值。
- 表述：`预测值 = 基期值 × (1 + Σ各因素增减率（按教材口径的迭加方式）)`
- ⚠️ 教材对"迭加"的具体算法存在表述差异，此式给出通行口径；若真题数据完整请以教材例题为准并核对。【2024-04 单选17（归属判别）、2024-10 计算38（产值 150 及多项增减率，原题数据待核实）】

## 五、应试提醒（丢分重灾区）

1. **先判断题型再动手**：给了"均值、标准差、样本量"→ 置信区间；给了"允许误差"→ 样本容量；给了"权数"→ 加权移动平均；给了"各层规模+σ"→ Neyman 分配。
2. **Z 值别用错**：95% 用 1.96；95.45% 用 2（自考卷偏爱后者）。
3. 公式先写字母式再代数字，**答案带单位**，最后写一句结论（如"有 95% 把握认为总体均值在……之间"）。
4. 加权移动平均**权重从近到远是 3、2、1**（近大远小），别倒挂。
5. 比例型样本容量中 p 未给出时取 0.5（样本最大、最保险）；题目给了 p 就用题给 p。
6. 计算器注意保留小数位数要求（如"保留两位小数"）；中间过程多保留一位，最后再四舍五入。
