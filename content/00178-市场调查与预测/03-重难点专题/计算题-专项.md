### 题型 1：加权移动平均预测法（第 38 题高频王者）

#### 1. 适用场景与判别特征
- **题干特征词**：给出连续多期历史数据序列（如 6~8 期销售量/销售额），明确给出**移动跨期 $n$（通常取 3 或 4）**与**权数分配（通常为 1、2、3 由远及近）**，要求预测下一期（如第 7 期、第 9 期）的数值。
- **核心逻辑**：近大远小——距离预测期越近的实际值对未来影响越大，赋予的权数越大。

#### 2. 标准计算公式
设移动跨期为 $n$，由远及近各期权数分别为 $w_1, w_2, \dots, w_n$：
$$\hat{Y}_{t+1} = \frac{\sum_{i=1}^{n} w_i \cdot X_{t-n+i}}{\sum_{i=1}^{n} w_i} = \frac{w_1 X_{t-n+1} + w_2 X_{t-n+2} + \dots + w_n X_t}{w_1 + w_2 + \dots + w_n}$$

#### 3. 解题模板步骤
1. **写出权数和**：$\sum w_i = w_1 + w_2 + \dots + w_n$（若权数 1、2、3，则分母 $= 1+2+3 = 6$）。
2. **确定参与计算的近 $n$ 期数据**：从序列中准确取出最后 $n$ 期的实际值 $X_{t-n+1}, \dots, X_t$。
3. **列式代入计算**：将各期数据与对应权数相乘、求和并除以权数和。
4. **得出结论并带单位**：写出规范的预测结论与计量单位。

#### 4. 真题实例
> **【2021-04 计算 38 / 2024-04 计算 38 重题】**
> 某产品连续 6 期的销售量（单位：百件）依次为：10、12、11、10、13、12。取跨期 $n = 3$，权数由远及近依次为 1、2、3。试用加权移动平均法计算第 7 期的销售量预测值。

**【标准解题演示】**
- **解**：
  1. 确定计算跨期 $n=3$，权数之和 $\sum w = 1 + 2 + 3 = 6$。
  2. 预测第 7 期销售量，截取距离第 7 期最近的第 4、5、6 期实际数据：
     - $X_4 = 10$（百件，权数 $w_1 = 1$）
     - $X_5 = 13$（百件，权数 $w_2 = 2$）
     - $X_6 = 12$（百件，权数 $w_3 = 3$）
  3. 列式代入加权移动平均公式：
     $$\hat{Y}_7 = \frac{1 \times X_4 + 2 \times X_5 + 3 \times X_6}{1 + 2 + 3} = \frac{1 \times 10 + 2 \times 13 + 3 \times 12}{6}$$
     $$\hat{Y}_7 = \frac{10 + 26 + 36}{6} = \frac{72}{6} = 12\text{（百件）}$$
  4. **结论**：该产品第 7 期的销售量预测值为 **12 百件**（或 1200 件）。

### 题型 2：总体均值置信区间估计（第 37 题高频王者）

#### 1. 适用场景与判别特征
- **题干特征词**：给出样本量 $n$（通常 $n \ge 30$ 大样本）、样本均值 $\bar{x}$、样本标准差 $s$（或总体标准差 $\sigma$），给出置信度（如 95% 或 95.45%），要求**估计总体均值的置信区间**。
- **常用临界值速记**：
  - 置信度 $95\% \implies Z = 1.96$（部分卷面若无特殊说明或取近似值 $Z=2$ 时需写明）
  - 置信度 $95.45\% \implies t = 2$ 或 $Z = 2$
  - 置信度 $90\% \implies Z = 1.645$
  - 置信度 $99.73\% \implies Z = 3$

#### 2. 标准计算公式
1. **抽样标准误差（标准误）**：
   $$SE = \sigma_{\bar{x}} = \frac{s}{\sqrt{n}}\quad (\text{或 } \frac{\sigma}{\sqrt{n}})$$
2. **抽样极限误差（允许误差）**：
   $$\Delta = Z \cdot SE = Z \cdot \frac{s}{\sqrt{n}}$$
3. **总体均值置信区间**：
   $$[\bar{x} - \Delta, \;\; \bar{x} + \Delta] \quad \text{或写为} \quad \bar{x} \pm \Delta$$

#### 3. 解题模板步骤
1. **标明已知参数**：列出 $n, \bar{x}, s$ 及给定的置信度对应的 $Z$ 值。
2. **计算标准误 $SE$**：代入 $s / \sqrt{n}$ 求出标准误。
3. **计算抽样极限误差 $\Delta$**：计算 $Z \times SE$。
4. **构造置信区间并写结论**：计算上下限，以业务语言表述置信把握度。

#### 4. 真题实例
> **【2021-04 / 2023-04 计算 37 重题】**
> 某公司对自己的 49 名客户进行调查，得到平均每次购买金额为 24.80 元，标准差为 5 元。试在 95% 的置信度下（$Z = 1.96$）估计总体平均每次购买金额的置信区间。

**【标准解题演示】**
- **解**：
  1. **已知参数**：
     - 样本容量 $n = 49$
     - 样本均值 $\bar{x} = 24.80$ 元
     - 样本标准差 $s = 5$ 元
     - 置信度 $1 - \alpha = 95\%$，对应临界值 $Z = 1.96$
  2. **计算抽样平均误差（标准误）**：
     $$SE = \frac{s}{\sqrt{n}} = \frac{5}{\sqrt{49}} = \frac{5}{7} \approx 0.714\text{（元）}$$
  3. **计算抽样极限误差**：
     $$\Delta = Z \cdot SE = 1.96 \times 0.714 \approx 1.40\text{（元）}$$
  4. **计算置信区间**：
     - 下限：$24.80 - 1.40 = 23.40$ 元
     - 上限：$24.80 + 1.40 = 26.20$ 元
  5. **结论**：在 95% 的置信度下，该公司所有客户平均每次购买金额的置信区间为 **[23.40 元, 26.20 元]**。

### 题型 3：分层最佳抽样分配（Neyman 分配法）

#### 1. 适用场景与判别特征
- **题干特征词**：总体被划分为若干层（通常为 3 层：如高、中、低收入层），已知各层的**总体容量 $N_i$** 与**层内标准差 $\sigma_i$**，给定**计划抽取的总样本量 $n$**，要求计算各层应分配抽取的样本容量 $n_i$。
- **原理**：规模越大、离散程度（标准差）越大的层，应分配更多的样本量。

#### 2. 标准计算公式
各层样本分配公式（Neyman 最佳分配）：
$$n_i = n \cdot \frac{N_i \sigma_i}{\sum_{j=1}^{k} N_j \sigma_j}$$
其中 $n$ 为总样本量，$N_i$ 为第 $i$ 层的总体单位数，$\sigma_i$ 为第 $i$ 层的标准差，$k$ 为分层总数。

#### 3. 解题模板步骤
1. **分别计算各层的乘积项 $N_i \sigma_i$**。
2. **计算加权乘积总和**：$\sum_{j=1}^k N_j \sigma_j$。
3. **计算各层样本量 $n_i$**：代入公式，注意四舍五入取整数。
4. **校验合计数**：检查各层样本量之和 $\sum n_i$ 是否精确等于总样本量 $n$。

#### 4. 真题实例
> **【2024-10 计算 37 真题】**
> 某城市共有家庭 20000 户。现按家庭月收入划分为三层：高收入层 2000 户（层内标准差 $\sigma_1 = 300$ 元）、中等收入层 6000 户（$\sigma_2 = 200$ 元）、低收入层 12000 户（$\sigma_3 = 50$ 元）。拟抽取总样本容量 $n = 200$ 户，试按 Neyman 最佳分配法计算各层应抽取的样本户数。

**【标准解题演示】**
- **解**：
  1. **计算各层总体容量与标准差的乘积 $N_i \sigma_i$**：
     - 高收入层：$N_1 \sigma_1 = 2000 \times 300 = 600{,}000$
     - 中等收入层：$N_2 \sigma_2 = 6000 \times 200 = 1{,}200{,}000$
     - 低收入层：$N_3 \sigma_3 = 12000 \times 50 = 600{,}000$
  2. **计算各层乘积总和**：
     $$\sum_{j=1}^{3} N_j \sigma_j = 600{,}000 + 1{,}200{,}000 + 600{,}000 = 2{,}400{,}000$$
  3. **计算各层应抽样本容量 $n_i$（总样本 $n=200$）**：
     - 高收入层：
       $$n_1 = 200 \times \frac{600{,}000}{2{,}400{,}000} = 200 \times \frac{1}{4} = 50\text{（户）}$$
     - 中等收入层：
       $$n_2 = 200 \times \frac{1{,}200{,}000}{2{,}400{,}000} = 200 \times \frac{1}{2} = 100\text{（户）}$$
     - 低收入层：
       $$n_3 = 200 \times \frac{600{,}000}{2{,}400{,}000} = 200 \times \frac{1}{4} = 50\text{（户）}$$
  4. **校验**：$n_1 + n_2 + n_3 = 50 + 100 + 50 = 200$（户），校验无误。
  5. **结论**：高收入层应抽 **50 户**，中等收入层应抽 **100 户**，低收入层应抽 **50 户**。

### 题型 4：必要样本容量 $n$ 确定

#### 1. 适用场景与判别特征
- **均值型容量**：给出方差 $\sigma^2$（或标准差 $\sigma$）、置信度 $t$（或 $Z$）、允许极限误差 $\Delta$，求 $n$。
- **成数（比例）型容量**：给出总体比例 $p$、置信度 $t$、允许极限误差 $\Delta$，求 $n$。
- **有限总体校正规则**：若总体规模 $N$ 已知，先算无限总体初值 $n$；若抽样比 $n/N > 5\%$，需采用公式 $n' = \frac{n}{1 + n/N}$ 进行有限总体校正。

#### 2. 标准计算公式
1. **总体均值估计时的样本容量**：
   $$n = \frac{t^2 \sigma^2}{\Delta^2}$$
2. **总体比例（成数）估计时的样本容量**：
   $$n = \frac{t^2 p(1-p)}{\Delta^2}$$
3. **有限总体修正公式**：
   $$n' = \frac{n}{1 + \frac{n}{N}} = \frac{N \cdot n}{N + n}$$

#### 3. 真题实例与疑点深度剖析
> **【2025-04 计算 38 真题】**
> 某灯泡厂生产一批灯泡共 10000 只，现要检验这批灯泡的不合格率。根据历史资料，灯泡不合格率 $p = 0.05\%$，在 95.45% 的置信度下（$t=2$），要求抽样极限误差 $\Delta \le 1\%$。试求应抽取的样本容量。

**【考场双轨解题演示与说明】**
- **解**：
  - **情形一（严格按题面 $p = 0.05\% = 0.0005$ 计算）**：
    $$n = \frac{t^2 p(1-p)}{\Delta^2} = \frac{2^2 \times 0.0005 \times (1 - 0.0005)}{0.01^2} = \frac{4 \times 0.0005 \times 0.9995}{0.0001} = \frac{0.001999}{0.0001} \approx 19.99 \approx 20\text{（只）}$$
    抽样比 $n/N = 20 / 10000 = 0.2\% < 5\%$，无需有限总体校正。样本容量为 **20 只**。
  - **情形二（针对原题 OCR 疑点：若历史不合格率实为 $p = 5\% = 0.05$）**：
    $$n = \frac{t^2 p(1-p)}{\Delta^2} = \frac{2^2 \times 0.05 \times 0.95}{0.01^2} = \frac{0.19}{0.0001} = 1900\text{（只）}$$
    此时抽样比 $n/N = 1900 / 10000 = 19\% > 5\%$，进行有限总体校正：
    $$n' = \frac{n}{1 + n/N} = \frac{1900}{1 + 0.19} = \frac{1900}{1.19} \approx 1596.6 \approx 1597\text{（只）}$$
- **应试策略**：答题时以情形一为主算，并在题末加注说明“若 $p=5\%$ 则修正后为 1597 只”，确保万无一失。

### 题型 5：二次移动平均预测法

#### 1. 适用场景与判别特征
- **题干特征词**：时间序列存在**明显的线性上升或下降趋势**，采用一次移动平均预测会出现明显的**滞后偏差**，题干要求采用“二次移动平均法”预测未来 $T$ 期的数值。

#### 2. 标准计算公式
设跨越期为 $N$：
1. **一次移动平均值**：$M_t^{(1)} = \frac{1}{N} \sum_{i=0}^{N-1} X_{t-i}$
2. **二次移动平均值**：$M_t^{(2)} = \frac{1}{N} \sum_{i=0}^{N-1} M_{t-i}^{(1)}$
3. **平滑参数（截距与斜率）**：
   $$a_t = 2M_t^{(1)} - M_t^{(2)}$$
   $$b_t = \frac{2}{N-1} (M_t^{(1)} - M_t^{(2)})$$
4. **线性预测方程**：
   $$\hat{Y}_{t+T} = a_t + b_t \cdot T \quad (T \text{ 为自当期起外推的期数})$$

#### 3. 真题实例
> **【2023-04 计算 38 规范算例】**
> 已知某产品时间序列经计算，第 10 期的一次移动平均值 $M_{10}^{(1)} = 120$ 万元，二次移动平均值 $M_{10}^{(2)} = 105$ 万元，移动跨期 $N = 4$。试建立预测模型并预测第 11 期（$T=1$）和第 12 期（$T=2$）的销售额。

**【标准解题演示】**
- **解**：
  1. **计算平滑参数 $a_{10}$ 与 $b_{10}$**：
     $$a_{10} = 2M_{10}^{(1)} - M_{10}^{(2)} = 2 \times 120 - 105 = 240 - 105 = 135\text{（万元）}$$
     $$b_{10} = \frac{2}{N - 1} \left(M_{10}^{(1)} - M_{10}^{(2)}\right) = \frac{2}{4 - 1} (120 - 105) = \frac{2}{3} \times 15 = 10\text{（万元）}$$
  2. **建立预测模型**：
     $$\hat{Y}_{10+T} = a_{10} + b_{10} \cdot T = 135 + 10 T$$
  3. **计算未来预测值**：
     - 预测第 11 期（$T = 1$）：$\hat{Y}_{11} = 135 + 10 \times 1 = 145$ 万元
     - 预测第 12 期（$T = 2$）：$\hat{Y}_{12} = 135 + 10 \times 2 = 155$ 万元
  4. **结论**：该产品第 11 期和第 12 期的预测销售额分别为 **145 万元** 和 **155 万元**。

### 题型 6：季节指数分析预测法

#### 1. 适用场景与判别特征
- **题干特征词**：给出按季度（1~4 季）或月份划分的多年历史数据表，要求计算各季度的**季节指数（季节比率）**，并根据全年预测总量预测指定季度的数值。

#### 2. 标准计算公式
1. **季度同季平均值** $\bar{X}_k$：多年第 $k$ 季度的算术平均值。
2. **总季度总平均值** $\bar{X}$：所有年份全部季度的总平均值（或各季同季平均值的均值）。
3. **季节指数（季节比率）**：
   $$S_k = \frac{\bar{X}_k}{\bar{X}} \times 100\% \quad (\text{四季指数之和应为 } 400\%)$$
4. **指定季度预测值**：
   $$\hat{Y}_{k} = \frac{\text{全年总预测值}}{4} \times S_k$$

#### 3. 真题演练与标准算例
> **【2022-10 计算 38 标准算例】**
> 某饮料企业测得第 1~4 季度的同季平均销售量分别为：150、300、450、100（万瓶）。预测明年的全年总销售量将达到 1200 万瓶。试求：① 各季度的季节指数；② 预测明年第 3 季度的销售量。

**【标准解题演示】**
- **解**：
  1. **计算总季度平均值 $\bar{X}$**：
     $$\bar{X} = \frac{150 + 300 + 450 + 100}{4} = \frac{1000}{4} = 250\text{（万瓶）}$$
  2. **计算各季度季节指数 $S_k$**：
     - $S_1 = \frac{150}{250} \times 100\% = 60\%$
     - $S_2 = \frac{300}{250} \times 100\% = 120\%$
     - $S_3 = \frac{450}{250} \times 100\% = 180\%$
     - $S_4 = \frac{100}{250} \times 100\% = 40\%$
     - 检验：$60\% + 120\% + 180\% + 40\% = 400\%$（检验合格）。
  3. **预测明年第 3 季度销售量**：
     - 明年季度平均预测值 $= 1200 / 4 = 300$（万瓶）
     - 第 3 季度预测值 $\hat{Y}_3 = 300 \times S_3 = 300 \times 180\% = 540$（万瓶）
  4. **结论**：各季季节指数分别为 60%、120%、180%、40%；明年第 3 季度预测销售量为 **540 万瓶**。

### 题型 7：四分位点内距（四分位差）计算

#### 1. 适用场景与判别特征
- **题干特征词**：给出一组未分组的样本数值（如 12 位专家的预测值），要求计算**四分位点内距（四分位差 $Q_d$）**。
- **核心概念**：$Q_d = Q_3 - Q_1$，反映排除了两端各 25% 极端值后中间 50% 数据的离散程度。

#### 2. 标准计算公式
将 $n$ 个数据按从小到大升序排序：
1. **下四分位数 $Q_1$ 位置**：$\text{Pos}(Q_1) = \frac{n + 1}{4}$
2. **上四分位数 $Q_3$ 位置**：$\text{Pos}(Q_3) = \frac{3(n + 1)}{4}$
3. **四分位点内距**：$Q_d = Q_3 - Q_1$

#### 3. 真题实例
> **【2025-04 计算 37 真题】**
> 某企业对某产品明年的销售量进行预测，征询了 12 位销售人员的个人预测值，数据（单位：万件）排序后为：19、20、23、23、24、25、26、26、28、28、30、32。试求这组数据的四分位点内距。

**【标准解题演示】**
- **解**：
  1. 样本容量 $n = 12$，数据已按升序排列：
     $x_{(1)}=19, x_{(2)}=20, x_{(3)}=23, x_{(4)}=23, x_{(5)}=24, x_{(6)}=25, x_{(7)}=26, x_{(8)}=26, x_{(9)}=28, x_{(10)}=28, x_{(11)}=30, x_{(12)}=32$。
  2. **确定 $Q_1$ 的位置并计算数值**：
     $$\text{Pos}(Q_1) = \frac{12 + 1}{4} = 3.25$$
     位于第 3 位与第 4 位之间，采用线性插值：
     $$Q_1 = x_{(3)} + 0.25 \times (x_{(4)} - x_{(3)}) = 23 + 0.25 \times (23 - 23) = 23\text{（万件）}$$
  3. **确定 $Q_3$ 的位置并计算数值**：
     $$\text{Pos}(Q_3) = \frac{3 \times (12 + 1)}{4} = 9.75$$
     位于第 9 位与第 10 位之间，采用线性插值：
     $$Q_3 = x_{(9)} + 0.75 \times (x_{(10)} - x_{(9)}) = 28 + 0.75 \times (28 - 28) = 28\text{（万件）}$$
  4. **计算四分位点内距**：
     $$Q_d = Q_3 - Q_1 = 28 - 23 = 5\text{（万件）}$$
  5. **结论**：这组销售预测数据的四分位点内距为 **5 万件**。

### 题型 8：基数迭加法（因素迭加预测）

#### 1. 适用场景与判别特征
- **题干特征词**：已知某指标的**基期基数 $Y_0$**（如去年产值 150 百万元），专家给出了影响未来增长的若干独立因素及其变动幅度 $r_1, r_2, \dots, r_k$（如政策 $+10\%$、技术 $+20\%$、成本 $-10\%$ 等），要求预测目标期数值。

#### 2. 标准计算公式
1. **各因素连乘模型（独立复合影响）**：
   $$\hat{Y} = Y_0 \cdot (1 + r_1) \cdot (1 + r_2) \cdots (1 + r_k) = Y_0 \prod_{i=1}^k (1 + r_i)$$
2. **各因素代数和模型（比重净增量迭加）**：
   $$\hat{Y} = Y_0 \cdot \left(1 + \sum_{i=1}^k r_i\right)$$

#### 3. 真题实例
> **【2024-10 计算 38 标准算例】**
> 某新能源装备企业 2022 年完成产值 150 百万元，拟采用基数迭加法预测 2023 年产值。经专家测算，影响该企业产值增长的四个独立因素变动率为：产业政策利好 $+10\%$、市场需求扩张 $+20\%$、原材料涨价制约 $-10\%$、技术升级增产 $+5\%$。试预测 2023 年产值。

**【标准解题演示】**
- **解**：
  1. 确定基期产值 $Y_0 = 150$ 百万元。
  2. 列出各影响因素变动系数：
     - $1 + r_1 = 1 + 10\% = 1.10$
     - $1 + r_2 = 1 + 20\% = 1.20$
     - $1 + r_3 = 1 - 10\% = 0.90$
     - $1 + r_4 = 1 + 5\% = 1.05$
  3. 代入连乘模型计算预测值：
     $$\hat{Y} = 150 \times 1.10 \times 1.20 \times 0.90 \times 1.05$$
     $$\hat{Y} = 150 \times 1.2474 = 187.11\text{（百万元）}$$
  4. **结论**：该企业 2023 年预测产值为 **187.11 百万元**。

## 📋 计算题应试避坑与提分清单（考场必读）

### 一、答题规范“三步踩分律”
1. **第一步：必写公式原形（2~3 分）**
   - 严禁直接写一串纯数字相乘除！必须先写出如 $\hat{Y} = \frac{\sum w_i X_i}{\sum w_i}$ 或 $\bar{x} \pm Z \frac{s}{\sqrt{n}}$ 的字母公式。即使后文数字算错，公式也能拿一半步骤分。
2. **第二步：代入数据分步列式（3~4 分）**
   - 规范写出中间过渡步（如计算出标准误 $SE=0.714$、极限误差 $\Delta=1.40$），方便阅卷老师逐项给分。
3. **第三步：最终结论带单位（2~3 分）**
   - 必须写“答：……”完整句，**务必带上题目对应的计量单位**（如万元、百件、户、只、%）。

### 二、高频易错与避坑提醒
- ⚠️ **移动平均跨期截取**：预测第 $t+1$ 期时，必须截取**最后 $n$ 期**（最靠近预测期的数据），千万别从第 1 期开始顺着算！
- ⚠️ **权数顺序**：加权移动平均中权数通常是“由远及近依次为 1、2、3”，即越近的数据乘越大的权数，切忌把权数颠倒。
- ⚠️ **置信度 $Z$ 值记忆**：
  - 95% 置信度 $\implies Z = 1.96$
  - 95.45% 置信度（$\pm 2\sigma$）$\implies t = 2$ 或 $Z = 2$
- ⚠️ **Neyman 最佳分配求和项**：在算分母 $\sum N_j \sigma_j$ 时，千万注意各层的 $N_i$（万人 vs 人、万元 vs 元）单位是否统一，统一单位后再相乘求和！
- ⚠️ **小数保留**：除不尽时，中间步骤保留 3~4 位小数，最终答案通常保留 **2 位小数**。
