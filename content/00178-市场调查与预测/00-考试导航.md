## 🧮 计算题轮换类型（37/38 题，每卷必出 2 题）

| 类型 | 出现考期 | 公式速查 |
|---|---|---|
| 置信区间估计 | 2021-04、2023-04、2024-04、2026-04 | x̄ ± Z·(s/√n)，Z(95%)=1.96、Z(95.45%)=2 |
| 样本容量 n | 2022-10、2025-04 | n=Z²σ²/Δ²；比例型 n=Z²p(1-p)/Δ² |
| 加权移动平均 | 2021-04、2023-10、2024-04、2026-04 | 详见 [[03-重难点专题/计算题-专项]] |
| 分层最佳抽样 | 2023-10、2024-10 | Neyman 分配 |
| 二次移动平均 / 季节指数 / 四分位点内距 / 基数迭加 | 2023-04 / 2022-10 / 2025-04 / 2024-10 | 同上 |

**重题实证**（题库抽题特征极明显，2026-09-09 原卷核对后已扩展为 17 套）：
- **计算 37 置信区间**：2021-04 = 2023-04 同题；2024-04 与 2017-10 同型（总额推算）。
- **计算 38 加权移动平均**：2021-04 = 2024-04 同题；2023-10、2026-04、2016-10 同型。
- **计算 37/38 分层最佳抽样**：2016-04 = 2024-10 同型；**2017-04 = 2024-10 完全同题**；2016-10 为最低成本扩展型。
- **新增确认（笔果版）**：2022-04 单选 1 = 2026-04 单选 1（信息时效性）；2021-10 单选 19 = 2016-04 单选 19（市场占有率/覆盖率）；2024-10 单选 3 = 2016-10 单选 4（整理流程）；2021-10 名解 27 = 2016-10 名解 26（原始信息）；2021-10 名解 28 = 2021-04 名解 27（抽样分布）。
- **二次移动平均**：2017-10 = 2023-04 完全同题；2019-04 同型（N=3）。
- **一次指数平滑**：2018-04 计算 37 = 2020-08 计算 38 完全同题；2017-04 计算 38 同型。
- **季节指数法**：2016-04、2018-04（计算季节指数）、2022-10 同型轮换。
- 选择题铁证重题：中位数（2016-04=2022-10 单选15）、等级量表（2016-10/2018-04/2019-04 连考）、**数据分类原则辨析——互斥性 vs 单一性**（2017-10/2021-10 答互斥；2019-04/2024-04 答单一性=分类基础唯一）、德尔菲法特征（2021-04/2023-04/2025-04/2026-04 连考）、"建议不必出现"（2019-04/2020-08/2024-04）等。
