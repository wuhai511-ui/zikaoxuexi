# 00178 主动背诵 V2 · P0

## 项目与接入

仓库 `wuhai511-ui/zikaoxuexi`：Quartz 5、TypeScript、Preact，`quartz.config.yaml` 管理社区插件和布局，`content/` 以章节、历年真题、专题、背诵手册、刷题、学习计划组织 Markdown。原有自定义样式为空，无学习状态组件。`enableSPA: false`，仍用 Quartz 的 `nav` 生命周期初始化；清理事件支持以后启用 SPA。

`.github/workflows/deploy.yml` 仅在 main 推送或手动运行时用 Node 22、npm ci、Quartz build 构建 public，然后发布 GitHub Pages。P0 不改该流程和 YAML 配置，不新增运行时依赖。`renderPage.tsx` 追加组件，组件只在“今日背诵”页面渲染；组件注册使 Quartz 打包浏览器脚本。其他页面和原始题库保持阅读方式。

## 题库治理

78 是原文编号数量：1–57 主干，58–78 补录。75 包含六篇论述，78 包含三篇论述，拆成 85 个题目变体，映射到 75 个知识点；这个数字是 P0 映射结果，并非已经确认的独立考纲考点总数。

题目结构：`questionId, knowledgePointId, sourceNumber, title, chapter, tags, exams, keywords, points, answer, answerHtml?, overlap?`。

`questionId` 按永久原文编号命名，例如 `00178-q029`；集合内子题为 `00178-q075-1`，不得重编号。`knowledgePointId` 是独立的身份，例如 `00178-kp029`。修改标题或移动原编号不会改变 ID。解析器在原文条数或拆题数量变化时显式失败，新增内容须先更新映射和测试。

## localStorage schema 与复习

键：`zikaoxuexi:00178:recall:v1`。

```json
{
  "version": 1,
  "questions": {
    "00178-q029": {
      "questionId": "00178-q029",
      "masteryStatus": "fuzzy",
      "reviewCount": 2,
      "lastReviewedAt": "2026-10-04T12:00:00.000Z",
      "nextReviewAt": "2026-10-06T12:00:00.000Z"
    }
  }
}
```

状态 known=会、fuzzy=模糊、unknown=不会；缺少记录=未学习。每次点击自评增加 reviewCount，保存成功才更新界面。不会 1 天、模糊 2 天、首次会 3 天；连续会按复习次数延长到 6/12/24/30 天，改为模糊或不会后缩短。到期按具体时间判断；今日完成是浏览器本地日期内自评过的不同题目数，反复点击同题不会增加今日题数。

今日队列：不会 > 模糊 > 到期 > 新题；未来到期的已掌握题不进入今日队列。自评时保持当前队列，避免正在看的卡片跳走；切换筛选或重新进入会重算队列。sessionStorage 保存筛选、当前 questionId 和滚动位置，刷新后隐藏答案重新回忆；localStorage 跨页面和重新打开保留掌握状态，多标签页通过 storage 事件同步。每日队列在打开和切换筛选时重新计算，长时间保持页面打开需切换筛选以更新到期状态。

存储读取失败、损坏或未知 schema 时保留原始值、阻止覆盖并显示提示；写入失败会显示未保存。清理浏览器数据、隐私模式限制或换设备会影响记录。P0 暂无导出导入、云同步和跨设备能力。
